# MVP Scope — Phase 1

## Allowed

- Utrecht, Netherlands only
- Premium mobile massage / wellness only
- Website (responsive) + PWA basics
- Dutch (primary) + English (secondary, next-intl)
- Customers: browse, book, pay, review
- Providers: profile, availability, accept bookings
- Admin: basic management dashboard
- Stripe payment processing, booking confirmation emails, reviews
- Provider dashboard: bookings, earnings, schedule
- Admin dashboard: users, bookings, payouts
- Google Maps address input, SEO-optimized pages, Supabase Auth (email + OAuth)

## Explicitly Forbidden

- In-app messaging / chat
- AI-powered matching or recommendations
- Subscription / membership plans
- Multi-provider bundle bookings
- Dynamic pricing / surge pricing
- Franchise or franchise onboarding flows
- B2B / corporate accounts
- Gift cards
- Referral program
- Provider earnings analytics beyond simple totals
- Customer loyalty points
- Waitlists
- Multi-city or national search
- Native push notifications (PWA web push only if simple)

## Rule

If requested feature is on the Forbidden list: decline and explain why it's post-MVP.
If unlisted: ask the user before building. Default answer is "not yet."
